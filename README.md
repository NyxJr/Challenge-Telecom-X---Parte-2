# Desafío Telecom X 💻– Parte 2: Predicción de Churn 📈

Este desafio se  enfoca en la segunda parte del Desafío Telecom X, donde nuestro objetivo es construir un sólido pipeline de Machine Learning para anticipar qué clientes tienen la mayor probabilidad de cancelar su suscripción.

## 🎯 Objetivo del Proyecto
A través de este análisis, buscaremos identificar los factores más influyentes en el abandono de clientes, permitiendo a la empresa tomar medidas proactivas para retenerlos.

- 🔍 Identificar con mayor precisión los **factores que influyen en la pérdida de clientes**.  
- 🎯 Proponer **estrategias efectivas de retención**.
